# Resonant Frequency vs. Temp Analysis
## Project Overview
A physics research project analyzing how temperature affects trumpet frequency by:
* Measuring frequency changes across temperatures
* Analyzing frequency spectrums
* Identifying statistical correlations
* Visualizing relationships

## Motivation
Understanding how temperature affects musical instruments can help musicians better prepare for performances in various conditions.

## Features
* Frequency spectrum analysis
* Temperature correlation studies
* Statistical significance testing
* Data visualization tools
* Automated measurement processing

## Technical Details
* Tools: Excel, SpectrumLab
* Environment: Windows
* Key concepts: Signal processing, statistical analysis, physics of sound


This project was developed as part of Science One at UBC.
